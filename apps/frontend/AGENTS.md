## Vite + TanStack Router

The frontend is a Vite single-page app: there is no Next.js and no server
rendering. In Docker, nginx serves the build (`var/docker/nginx.conf`).

- Routes are the files under `src/app` (TanStack Router file-based routing):
  `route.tsx` is the layout of its folder, `index.tsx` its page, `$name` a path
  parameter, `_name` a layout that adds nothing to the URL and `(name)` only
  groups files. `src/routeTree.gen.ts` is generated by the Vite plugin, don't
  edit it. Route files only export `Route`.
- `src/app/__root.tsx` holds the redirects that every page goes through (login,
  logout, invites), what the Next.js middleware used to do.
- Navigation: the hooks of `@gitroom/react/helpers/navigation` (`useRouter`,
  `usePathname`, `useSearchParams`, `useParams`), and `Link` from
  `@tanstack/react-router` with `href`.
- A component loaded on first render: `dynamic` from
  `@gitroom/react/helpers/dynamic`.
- Page titles: the `head` option of the route.
- Settings that change without a rebuild come from the environment through
  `runtime.config.mjs` (written to `/config.js` when the server starts), read
  with `useVariables()`, or `runtimeVariables()` outside React. Only
  `process.env.NEXT_PUBLIC_*` is inlined at build time, any other `process.env`
  read is `undefined` in the browser.
